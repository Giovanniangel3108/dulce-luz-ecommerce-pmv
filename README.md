# Dulce & Luz Artesanal - Plataforma E-Commerce (PMV v0.1)

Proyecto productivo desarrollado en el marco de la etapa productiva del programa **Tecnólogo en Análisis y Desarrollo de Software (ADSO)** - SENA Regional Cauca.

## Descripción del Proyecto
Plataforma web responsiva orientada a la comercialización B2C (clientes finales) y B2B (eventos y empresas) de minidonas artesanales y velas aromáticas personalizadas en Santander de Quilichao, Cauca.

## Alcance de esta versión (Avance 01 - Bitácora 03)
- Maquetación semántica y responsiva (*Mobile-First*) con HTML5 y CSS3.
- Renderizado dinámico del catálogo de productos mediante arreglos de objetos en JavaScript puro (Vanilla JS).
- Formulario interactivo de personalización de pedidos y cálculo automático de subtotales y total general en el resumen de compra.

## Tecnologías utilizadas
- HTML5
- CSS3 (Variables CSS y CSS Grid)
- JavaScript (ES6+ / Manipulación del DOM)
- Git y GitHub para control de versiones
